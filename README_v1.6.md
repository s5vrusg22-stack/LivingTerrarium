# Living Terrarium 3D v1.6 — procedural mantis model, 20 passes

Extends v1.5 with twenty named, visible geometry enhancements to the existing animated mantis model: dorsal pronotum keel, side ridges, collar, neck, frontal shield, median ocellus, lateral ocelli, clypeal suture, labrum, mandibles, maxillary palps, antennal sockets, antennal tips, tegmina, wing veins, cross-veins, spiracles, pleural plates, cerci, and foreleg spines.

The geometry is attached to existing head, abdomen, thorax, feeler, and foreleg nodes so it moves with those procedural joints. Existing animation states, foot IK, textures, UI, and simulation code are preserved.

**Limits:** These are stylized meshes, not photogrammetry, a Blender-authored GLB, a complete biological reconstruction, or a fashion/garment model. Godot engine and Android APK execution have not been tested here.

**Static validation:** Run `python3 tests/check_v16.py` from the project directory.

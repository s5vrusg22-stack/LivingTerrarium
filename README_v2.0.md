# Living Terrarium 3D v2.0 — 오류·그래픽 개선

v1.9를 기반으로 업데이트했습니다.

- v0.9/v1.0에서 남아 있던 두 개의 구형 정적 테스트를 현재 발 고정 구조에 맞게 업데이트했습니다.
- 사마귀의 여섯 다리 발 목표 위치를 전후로 분산하고, 휴식 중 강제 발 재배치를 줄였습니다.
- 잎 메시를 곡면 8분할 형태로 교체하고 정점 색상 기반 엽맥/색상 변화를 추가했습니다.
- 식물 잎 회전 변이를 확대했습니다.
- 먹이 곤충의 등판 3개와 좌우 날개 덮개를 추가했습니다.
- 사용자가 배치한 돌에 기존 stone albedo/normal/roughness 재질을 실제 적용했습니다.
- 사육장 프레임에 저비용 모서리 트림을 추가했습니다.
- 텍스처 15개를 열어 파일 무결성을 검사하는 회귀 테스트를 추가했습니다.

**한계:** Godot 엔진과 Android SDK가 없는 환경에서 작성하여 Godot 런타임 실행·시각 검증 및 APK 빌드는 수행하지 못했습니다. 테스트는 소스 구조와 파일 무결성을 확인하는 정적 검사입니다. 정교한 GLB 리깅이나 실제 사진 기반 PBR 재질은 포함되지 않습니다.

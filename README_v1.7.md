# Living Terrarium 3D v1.7 — 살아 움직이는 사육장

v1.6 기반 통합 업데이트. Godot 4 프로젝트.

## 추가된 움직임
1. 식물 줄기 전체의 바람 흔들림
2. 잎마다 서로 다른 위상과 탄성의 흔들림
3. 저주파 돌풍 변화
4. 잎 색상과 크기, 방향 다양화
5. 먹이 곤충의 여섯 다리 보행
6. 먹이 곤충의 더듬이 탐색
7. 부유 미세 입자 움직임
8. 바람 켜기/끄기 및 세기 조절 UI

## 구현 범위
24개 절차적 식물, 총 2~4개 잎/식물, 14개 미세 입자. 단순 메시와 소량의 노드 업데이트로 모바일 성능을 고려함. 기존 사마귀 애니메이션, 사냥, 환경 설정, 저장 기능 유지.

**제약:** 실제 바람 유체역학, 식물 뼈대 리깅, 곤충의 정밀한 물리 보행은 아님. Godot 엔진 및 Android 기기 실행 검증은 별도 필요.

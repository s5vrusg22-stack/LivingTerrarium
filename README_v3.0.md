## 범위와 한계
이 50개는 코드 및 구조 개선·검사 항목이며 Godot 엔진의 50개 런타임 테스트를 뜻하지 않습니다.
관절 각도는 보수적인 추정치이며 실측 생체역학 값이 아닙니다. GLB 메시 가중치와 61개 스킨 관절은 v2.9 그대로 유지합니다.
실제 Godot 렌더링, 리그 왜곡, Android 성능은 별도 검증이 필요합니다.
